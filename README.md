# EduSphere CenterHub

Multi-centre website and management platform for **EduSphere Academy**. Each centre gets its own public
website, a centre admin panel, and a student portal; a super-admin manages the corporate site and all centres.

## Features

- **Public websites** — corporate site plus one site per centre (`/{centre-slug}`): hero slider, courses,
  results, testimonials, gallery, blog, news, FAQ, careers, enquiry forms, light/dark mode, SEO settings
- **Centre admin** (`/admin/{centreId}`) — content, enquiries, students, batches, attendance, assessments,
  course fees and payments, employees, expenses, reports, roles and permissions
- **Student portal** (`/{centre-slug}/student`) — login (password or OTP), courses, materials, tests,
  fee instalments, online payment (Razorpay), AI tutor
- **Super admin** (`/super-admin`) — centres, admins, course catalogue, website home page, menus,
  approvals, analytics, global settings

## Tech stack

Next.js 14 (App Router) · TypeScript · Tailwind CSS · **MySQL 8+ / MariaDB 10.4+** (`mysql2`) ·
Socket.IO (custom `server.js`) · optional Redis · SendGrid · Razorpay · OpenRouter

## Getting started

Requirements: Node.js 20+, a MySQL 8+ or MariaDB 10.4+ server.

```bash
npm install
cp .env.example .env        # fill in DB_* and JWT_SECRET at minimum
npm run db:setup            # creates the database and all tables (drops existing ones!)
npm run db:seed             # loads demo data
npm run dev                 # http://localhost:<PORT> (2500 in .env.example)
```

Use `npm run dev` / `npm start` (both run `server.js`) rather than `next dev`, so real-time
notifications over Socket.IO work.

## Database

- Schema: [`migrations/mysql/schema.sql`](migrations/mysql/schema.sql) — the single source of truth.
- After changing the schema, run `npm run db:meta` to refresh `lib/mysql-schema-meta.json`
  (JSON columns and auto-increment keys used by the data layer).
- `lib/db.ts` exposes `pool.query(sql, params) → { rows, rowCount }` and `pool.connect()` for
  transactions. Queries are written with `$1, $2…` placeholders; `lib/sql-translate.ts` rewrites
  them for MySQL and emulates `RETURNING`, `ON CONFLICT`, `ILIKE`, `::` casts and `FILTER (WHERE …)`.
  For anything else (JSON aggregation, date arithmetic) write plain MySQL.
- `npm run db:check-sql` validates every SQL statement in the code against the live schema
  (`EXPLAIN`, nothing is executed). Run it after schema or query changes.

## Branding

The name, product name, default email domain, SMS sender ID and app-store links live in
[`lib/brand.ts`](lib/brand.ts). Logos, favicon and default banners are in `public/assets/img/` and
are generated by `node scripts/brand/render-brand-assets.js`. Site name, tagline, contact details,
colours and per-centre logos are editable in **Super Admin → Settings**.

## Production checklist

- Strong `JWT_SECRET`; real `SENDGRID_*`, `RAZORPAY_*`, `OPENROUTER_*` keys
- Replace the placeholder domain `edusphere.example.com` in `lib/brand.ts`
- `DATABASE_SSL=true` with `DATABASE_CA_CERT` for a remote database
- Optional: `REDIS_URL` for rate limits; `VIRUS_SCAN_ENABLED=true` + `VIRUS_SCAN_URL` for uploads
- Schedule `npm run cron:installment-reminders` daily
